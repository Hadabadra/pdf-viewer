מנוע הזיהוי
Tesseract מובנה (עובד בלי אינטרנט), או OCR של Windows דרך הגשר
איכות הזיהוי
רזולוציה גבוהה: מדויק יותר ואיטי יותר
שמירת חלוקת השורות
להשאיר את השורות כמו במקור
OCR של Windows (דרך הגשר)
הגשר הוא שירות קטן שמותקן במחשב, ואינו חלק מהתוסף. מורידים אותו פעם אחת, מפעילים אותו, ומתקינים ב-Windows את חבילת השפה העברית (הגדרות ← זמן ושפה ← שפה ← עברית ← אפשרויות שפה ← זיהוי טקסט). אחר כך לוחצים "בדיקת חיבור". בלי הגשר או בלי החבילה, ממשיכים עם Tesseract.
