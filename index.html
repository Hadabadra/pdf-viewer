            תקריב ברירת מחדלבמסמך שנפתח בפעם הראשונה

            שילוב באוצריא

            הקבצים שלי בחיפוש הספרייהקבצי PDF מ"התיקיות שלי" יופיעו באיתור הספרים של אוצריא, ונפתחים כאן
            כפתור "פתח ב-PDF+OCR"בסרגל הקורא של ספרי PDF

            קיצורי מקשים

            • Ctrl+O פתיחה · Ctrl+F חיפוש · Ctrl+E חילוץ טקסט · Ctrl+R OCR לאזור
            • PageUp/PageDown מעבר עמוד · Home/End תחילה/סוף · Ctrl+G קפיצה לעמוד
            • Ctrl++/Ctrl+- תקריב · Ctrl+0 התאמה לרוחב · Ctrl+] סיבוב
            • במסך הקריאה של אוצריא: "פתיחת ספר ה-PDF הנוכחי בצופה" — ניתן להגדרה בהגדרות → קיצורי מקשים

            מנוע ה-OCR

            Tesseract.js מובנה בתוסף, כולל עברית — עובד בלי אינטרנט. לזיהוי טוב יותר, המסמך מעובד ברזולוציה גבוהה מזו שעל המסך.

            מסמך בשני טוריםמזהה כל טור בנפרד (ימין ואז שמאל), כדי שהטורים לא יתערבבו
            מנוע הזיהויTesseract המובנה, או OCR של Windows דרך גשר אוצריא
            איכות הזיהוירזולוציה גבוהה = מדויק יותר ואיטי יותר
            שמירת שורותלהשאיר את חלוקת השורות של המקור

            OCR של Windows (דרך הגשר)

            מנוע הזיהוי המובנה של Windows פועל דרך "גשר אוצריא" — שירות קטן שמותקן במחשב. הוא אינו חלק מהתוסף, ולכן צריך להוריד אותו פעם אחת.

            1. לחצו "הורדת הגשר", והורידו את הקובץ OtzariaBridge.exe מעמוד הגרסה האחרונה.
            2. הפעילו אותו (הוא רץ ברקע ומופיע במגש המערכת). אם Windows מזהיר — "מידע נוסף" ← "הפעל בכל זאת".
            3. ב-Windows: הגדרות ← זמן ושפה ← שפה ← עברית ← אפשרויות שפה ← "זיהוי טקסט" (OCR) ← התקנה.
            4. חזרו לכאן ולחצו "בדיקת חיבור", ואז בחרו "OCR של Windows" במנוע הזיהוי.

            צופה PDF+OCR

            פתיחת קבצי PDF, תמונה ומסמכים באוצריא — עם חיפוש, תוכן עניינים, בחירת טקסט וזיהוי טקסט (OCR) בעברית.

            מאת חד בדרא · נבנה בעזרת Claude

            מה חדש

            תיקונים לפי הערות המשתמשים בפורום: פוסט 43255 · פוסט 43381

            3.5.2
            • תיקון אותיות משובשות בכותרות ובדפוסים ישנים: צורות האותיות נלקחות מהקובץ עצמו ולא מגופן המחשב.
            3.5.1
            • חלונית „מה חדש“ מעודכנת ומקשרת לפוסטים בפורום.
            3.5.0
            • שינוי רוחב סרגל הצד וחלונית הטקסט בגרירה (לחיצה כפולה מאפסת).
            • Ctrl+E (חילוץ טקסט) ו-Ctrl+R (OCR לאזור) עובדים גם כשהמיקוד במסמך.
            • תפריט החילוץ: שמות ברורים, „זיהוי טקסט (OCR) לאזור מסומן“ ראשון, והחילוץ המוטבע נפרד מה-OCR.
            • OCR בשני טורים: מתג בהגדרות ← OCR, מזהה כל טור לחוד (ימין ואז שמאל).
            • OCR של Windows: נדרש גשר אוצריא 1.5 ומעלה וחבילת OCR לעברית ב-Windows (הכפתור בהגדרות ← OCR).
            3.4.0
            • התאמה לגובה בתפריט הזום ובהגדרות.
            • חיצים ימינה ושמאלה מעבירים עמוד בכל מצבי ההתאמה.
            • סרגל החיפוש במסמך צר יותר.
            3.3.3
            • כתב ברור יותר: נוספו מפות התווים (CMaps) לגופנים עבריים לא מוטבעים, ורינדור חד פי 2.
            3.2.0
            • תיקון אותיות משובשות בכותרות ובדפוסים ישנים (גופני PDF סטנדרטיים).

            לשוניות, זיכרון לשוניות, מסך מלא מורחב ומצב יד קיימים בתוסף „ספריית PDF+OCR“.

            3.0.0
            • עיצוב חדש לגמרי, תואם לממשק של אוצריא (כולל מצב כהה וגופני הקריאה שלכם).
            • גלילה רציפה, עמודים ממוזערים, תוכן עניינים, קפיצה לעמוד, סיבוב ותקריב חכם.
            • חיפוש בתוך המסמך (גם בלי ניקוד), ובחירת טקסט ישירות מהעמוד.
            • OCR לאזור מסומן ולכל המסמך, וטקסט שאפשר לערוך, לשמור כקובץ, להדפיס ולייצא ל-PDF.
            • "התיקיות שלי": עיון בקבצים מתוך התוסף — וקבצי ה-PDF שבהן מופיעים בחיפוש הספרייה של אוצריא.
            • "אחרונים" נפתחים מיד בלי לבחור שוב, וחוזרים לעמוד שבו הפסקתם. ספרי PDF מהספרייה נפתחים בעמוד שבו אתם נמצאים.
            • קיצור מקשים מהקורא של אוצריא, תמיכה בתצוגה באנגלית, ו-TIFF מרובה עמודים.

            משוב

            טוב לדעת

            • בספרי PDF של הספרייה: הכפתור "פתח ב-PDF+OCR" בסרגל הקורא פותח כאן את קובץ הספר עצמו, בעמוד שבו אתם נמצאים.
            • גזרת מסך (Win+Shift+S) והדבקה כאן מחלצת טקסט מכל דבר שרואים על המסך.
            • תפריט הלחיצה הימנית של אוצריא אינו פעיל במסך PDF — לכן הפעולות שם נמצאות בסרגל הקורא.
            • גודל התוסף נובע ממנוע ה-OCR המובנה, כדי שיעבוד גם בלי רשת.
            גררו לסימון האזור, ואז "חלץ מהבחירה" (Esc לביטול)
