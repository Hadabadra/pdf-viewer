# מודל כתב יד — משקפת (Mishkefet-v1)

קובץ המודל לצופה PDF+OCR מגרסה 6.1.0. הצופה מוריד אותו פעם אחת ושומר במחשב.
בלי רשת: מורידים את `mishkefet-v1.bin` ובוחרים אותו בהגדרות ← OCR ← „בחירת קובץ מודל“.

המודל: Mishkefet-v1 של איתי ענבר. מבנה הקובץ: `MKF1`, אורך כותרת (uint32 LE), כותרת JSON, ואחריה wasm, model, lm, words.
